# CampusMate (캠퍼스메이트)

같은 학교 학생이라는 신뢰를 바탕으로, 대학 생활의 시작과 전환점에 필요한 사람과 정보를 연결해 주는 캠퍼스 생활 플랫폼의 데모 프로토타입이에요.

- 사이트 (GitHub Pages): https://ysyny1126-bot.github.io/campusmate/
- 데모 링크 (Claude): https://claude.ai/artifact/1GzyUtTWnDz6NwPFAwfjAs
- 전체 기획·기능 정리: [PROJECT_SUMMARY.md](PROJECT_SUMMARY.md)

## 주요 기능
- **룸메이트 매칭**: 생활 습관 설문 + 문항별 중요도로 계산한 양방향 호환도, 매칭 이유 설명, 서로 관심 후 프로필 공개
- **방 찾기**: 지도 + 리스트, 필터, 거주 증빙 배지, 송금 경고, 허위 매물 필터
- **중고거래 · 무료 나눔**: 교내 안전 거래 장소, 상호 후기와 신뢰도
- **동아리 · 행사**: 신입생·복학생 맞춤 추천, 앱 내 지원, 익명 Q&A, 행사 캘린더
- **프로젝트 · 공모전**: 공모전 D-day·스크랩, 포지션별 팀원 모집, 팀 구해요, 완주율
- **커뮤니티**: 학교 인증 학생 전용, 익명 글쓰기, 신고·차단
- **마이페이지**: 인증 상태, 신뢰도 점수와 배지, 활동 내역

## 실행
빌드가 필요 없는 정적 사이트예요. `index.html`을 브라우저로 열면 돼요.
로컬 서버로 열려면 이 폴더에서 아래 명령을 실행하고 http://localhost:8000 에 접속하세요.

```bash
python3 -m http.server 8000
```

## iOS 앱 (Xcode)
웹 프로토타입을 WKWebView로 감싼 iOS 앱이 `ios/` 폴더에 있어요.

1. `ios/CampusMate.xcodeproj`를 Xcode로 열어요.
2. 상단에서 iPhone 시뮬레이터를 고르고 ▶︎(Run)을 눌러요.

빌드할 때마다 저장소 루트의 `index.html`, `css/`, `js/`가 앱 번들의 `Web` 폴더로 복사돼서, 웹을 고치면 앱에도 그대로 반영돼요. 인터넷이 없어도 열리고, 폰트만 온라인일 때 받아와요.

## 구조
| 파일 | 역할 |
|---|---|
| `index.html` | 기본 틀 (상단 바, 하단 탭 바, 모달·토스트 영역) |
| `css/styles.css` | 디자인 토큰과 컴포넌트 스타일 |
| `js/data.js` | 한국어 더미 데이터 |
| `js/app.js` | 라우팅, 화면 렌더링, 매칭 계산, 가짜 인증·채팅·지도, 폼 처리 |
| `ios/` | 웹을 감싼 iOS 앱 (SwiftUI + WKWebView) |

## 데모 사용법
- 상단 **학교 인증** → 아무 아이디 입력 → 화면에 표시되는 인증번호 입력
- 룸메이트 `도서관지박령`에게 관심을 보내면 바로 서로 관심이 되어 채팅이 열려요
- 마이페이지 하단 **데모 데이터 초기화**로 처음 상태로 돌아가요

인증·채팅·지도·업로드·알림은 화면만 구현된 데모예요. 학교·인물·기관·매물·후기는 모두 가상의 데이터예요.
